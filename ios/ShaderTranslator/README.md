# Встроенный переводчик GTA для iPhone

Приложение содержит `GtaShaderAot.framework` (NativeAOT, ARM64 iOS) и статический
SPIRV-Cross C ABI. На телефоне не нужны .NET/JIT, Python, внешний процесс или Mac.
Цепочка совпадает с существующим GTA `totk-native-v4-unverified`.

`artifacts.json` фиксирует SHA всех входных артефактов. `build_ipa_gta.py` проверяет
их и включает framework в `GTA.app/Frameworks`; `install_device_gta.py` подписывает
вложенный framework до внешнего приложения. Статическая библиотека подключена
через `project.yml`. Компоненты переводчика не содержат данные игры.

Исходные bridge-файлы: `ios/Sources/gta_shader_translator.mm/.h`.
Запросы принимаются только с кодом собственного варианта в каталоге кеша;
MSL и reflection публикуются атомарно до записи индекса. Успешный результат
сохраняется в Documents и повторно используется при следующем запуске.

Фоновый worker использует один поток со стеком 8 МиБ и utility QoS. Критичные
операции, результат которых нужен последующим кадрам, сохраняют ожидание.
Компиляция неизвестного варианта требует времени; кеш не обещает все возможные
сочетания форматов и ресурсов игры.

Проверенные исходники прототипов, воспроизводящие сборку NativeAOT/SPIRV-Cross,
параметры и независимые тесты находятся в приватном каталоге, указанном в
`artifacts.json` (`provenance`). Не обновляйте один бинарник без проверки всей
цепочки и соответствующего manifest.
